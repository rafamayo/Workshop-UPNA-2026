# Lightweight Evaluation Rubric for Group Activity

This rubric is optional and intended for quick formative feedback.  
Each category is scored from 0–2 points.

---

## 1. Problem Definition (0–2 points)
**0:** Unclear; scenario incomplete or unrealistic  
**1:** Reasonably defined clinical scenario  
**2:** Clear scenario with well-defined actors and purpose  

---

## 2. FHIR Data Design (0–2 points)
**0:** No meaningful use of FHIR resources  
**1:** Some correct resources identified (Patient, Observation)  
**2:** Accurate and appropriate use of FHIR resources and coding systems  

---

## 3. REST Interaction Design (0–2 points)
**0:** No API interactions defined  
**1:** Basic GET requests identified  
**2:** Clear workflow with relevant GET and POST examples  

---

## 4. Workflow Logic (0–2 points)
**0:** No clear sequence of steps  
**1:** Some logical sequence  
**2:** Clear end-to-end workflow with data flow logic  

---

## 5. Optional AI Component (0–2 points)
**0:** Missing or unrelated  
**1:** Basic idea (e.g., threshold check)  
**2:** Coherent, simple idea tied to the workflow (trend, rule-based advice)  

---

## 6. Risks / Limitations (0–2 points)
**0:** None mentioned  
**1:** One reasonable limitation identified  
**2:** Multiple relevant risks or assumptions  

---

## Maximum Score: 12 points  
Use this only for feedback or quick ranking, not formal assessment.
