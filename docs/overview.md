# Workshop Overview — UPNA 2026

**FHIR, RESTful APIs, Web Apps & Standards for AI in Healthcare**

This workshop forms part of the “Clinical Information Systems” module in the **B.Sc. in Biomedical Engineering** at **Universidad Pública de Navarra (UPNA)**. It is delivered within the framework of the Erasmus+ teaching mobility program in Spring 2026.

The goal of the workshop is to provide students with a **practical, hands-on introduction to healthcare interoperability**, with a focus on:

* **FHIR (Fast Healthcare Interoperability Resources)**
* **RESTful APIs and clinical data exchange**
* **Client-side applications interacting with a FHIR server**
* **How standards such as FHIR support the development of trustworthy AI in healthcare**

Students will engage in interactive sessions, structured labs, a simplified web application demonstration, and a short design-based group activity.

---

## Learning Objectives

By the end of the workshop, students will be able to:

1. **Explain the purpose and structure of FHIR** and how it enables interoperability between healthcare IT systems.
2. **Use RESTful APIs** to create, read, search, and link resources on a FHIR server.
3. **Model simple clinical workflows** (Patient → Observations → DiagnosticReport) using standard FHIR resources.
4. **Understand how web applications interact with FHIR servers**, focusing on basic HTTP requests and JSON responses.
5. **Discuss the relationship between interoperability standards and AI**, including how structured, semantically rich data supports safe and effective AI applications.
6. **Design a small, realistic clinical use case** using FHIR resources and—optionally—simple AI or alerting logic.

---

## Teaching Approach

The workshop emphasizes:

* **Active, hands-on learning**, using cloud-based tools to minimize setup issues.
* **Short, focused theory segments** followed by applied practice.
* **Collaborative problem-solving**, especially during the group activity.
* **Clinical relevance**, using examples aligned with biomedical engineering practice.
* **Light integration of AI concepts**, keeping the focus on data quality and standards rather than complex machine learning.

---

## Prerequisites

Students should have:

* Basic knowledge of **JSON**
* Basic understanding of **HTTP/REST** concepts
* Prior exposure to the idea of **electronic health records** (from the main course module)

Programming experience is helpful but not required; all code is scaffolded.

---

## Structure

The workshop is divided into two sessions:

* **Day 1 (4 hours):**
  FHIR & REST fundamentals + hands-on labs building a mini clinical workflow
* **Day 2 (2 hours):**
  Web application demo + AI/standards mini-module + group use case design activity
